# 백엔드 에이전트 작업 규칙

- 백엔드 작업을 시작하기 전에 이 디렉터리의 [README.md](README.md)를 직접 읽습니다. 이전에 읽었다는 기억만으로 확인을 생략하지 않습니다.
- README의 코드·테스트 작성 규칙은 필수로 준수합니다. 기존 코드에 다른 작성 방식이 있어도 이를 근거로 규칙을 생략하지 않습니다.
- 작업 완료를 알리기 전에 변경한 코드와 테스트를 README의 규칙과 대조하고, 어긋난 부분을 정리한 뒤 필요한 검증을 수행합니다.
- 사용자의 명시적인 지시가 README의 규칙과 다르면 사용자 지시를 우선합니다.
